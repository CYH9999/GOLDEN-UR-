# سكربت التحقق

اختبارات مؤقتة للتحقق من محرّك الحساب. **الإنتاج لا يعتمد عليها إطلاقاً**:
`index.html` يبقى ملفاً واحداً بلا مكتبات ولا طلبات شبكة.

الطريقة: `tests/harness.js` يقرأ وسم `<script>` من `index.html` ويشغّله فوق
DOM مزيّف داخل Node، فلا يُنسخ أي كود — أي تعديل بالبرنامج ينعكس على
الاختبار فوراً. `tests/verify.js` يشغّل دوال الحساب والحفظ الحقيقية.

```
node tests/verify.js
```

للمقارنة مع بناء سابق (يتأكد أن الحالات العادية ما تغيّرت):

```
git show <commit>:index.html > /tmp/old.html
OLD_HTML=/tmp/old.html node tests/verify.js
```
